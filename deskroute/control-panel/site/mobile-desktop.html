mobile desktop

Your support workspace, wherever you work.

One responsive web app for a phone, tablet or desktop.

01

Install from your browser

Use the browser’s Install option on supported devices. On iPhone and iPad, use Safari’s Share → Add to Home Screen.

02

Keep human work close

Open the Human Queue, read alerts and continue a conversation from the mobile navigation.

03

Know when alerts arrive

In-app alerts refresh while DeskRoute is open. Closed-app push notifications are not enabled in this release.

04

An honest offline state

The app shell can load offline, but conversations and changes require a connection. Customer data is not put into the service-worker cache.
