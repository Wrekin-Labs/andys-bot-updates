# SenseVeil AI — Brand & UI system

## Product
**SenseVeil AI**  
**See the signal. Verify the source.**

Positioning: a handheld multisensor presence and anomaly scanner. The product should feel technical, evidence-first and intriguing without presenting an AI classification as proof of a paranormal cause.

## Mark
The core mark is a circular sensing aperture with two opposing signal arcs and a central data point. It can read as an eye, radar emitter or measurement instrument without using a literal ghost.

Use the standalone mark for the launcher icon and compact HUD. Pair it with the `SENSEVEIL AI` wordmark in wider contexts.

## Palette
- Background: `#05080B`
- Panel: `#D90B1015` / opaque equivalent `#0B1015`
- Cyan / vision: `#42E8FF`
- Magenta / anomaly or external sensor: `#FF4FD8`
- Green / confirmed human vision: `#6CFF8F`
- Amber / caution or Lab readout: `#FFD166`
- Primary text: `#EAFBFF`
- Muted text: `#8799A3`

## Signal semantics
- Cyan = normal vision/scan state
- Green = human-like vision detection with supporting evidence
- Amber = caution, raw Lab information, degraded/estimated data
- Magenta = disagreement/anomaly or external radar/thermal presence
- Never use magenta alone to imply a supernatural conclusion

## Field mode
Designed for one-handed use in a dark environment. Priorities: camera, detection label, confidence, estimated distance, radar glance, capture and torch.

## Lab mode
Shows detector components rather than a simplified conclusion: pose-landmark count, body score, object count, field novelty, magnetometer, ambient light, pressure and audio level when sensors are available.

## Typography
Use Android system sans for normal labels and system monospace for telemetry. Avoid decorative horror fonts; the interface should look like instrumentation.

## Motion
Radar sweep may animate continuously at low cost. Detection boxes and skeletons should update directly from inference without decorative jitter. Anomaly alerts use one short haptic pulse rather than repeated vibration so the phone does not contaminate its own magnetometer readings.

## Language
Prefer: `HUMAN-LIKE`, `RADAR PRESENCE`, `MODEL / SENSOR DISAGREEMENT`, `EST`, `RAW`.
Avoid: `GHOST FOUND`, `SPIRIT CONFIRMED`, or any label that turns a sensor/model result into an unsupported claim.
